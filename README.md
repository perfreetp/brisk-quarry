# 应急演练场地布点工具

基于 **Vue 3 + three.js + Vite** 的三维应急演练场地布置工具：在一块长方形空地上按规则
铺开帐篷、集结点、物资堆放区、警戒桩，支持手动拖拽/旋转/改尺寸、种子复现，以及导出带
尺寸与间距标注的俯视布置图。

## 启动

```bash
npm install
npm run dev        # 开发模式，默认 http://127.0.0.1:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
npm test           # 引擎逻辑单测（11 项）
node tests/smoke.mjs <preview 地址>   # 无头 Chrome 端到端检查（需先 build + preview）
```

## 操作流程（对应需求）

1. **左侧设定场地**：长、宽（20–200m）、主通道走向（沿长度/沿宽度）、通道宽度。
2. **设定数量档位**：四类物件各有「关闭 + 五档」，档位对应固定数量。
3. **填种子并点「生成布置」**：地面与物件按规则自动铺开。
   - 同类型物件之间保持设定的净间距（帐篷 3m、集结点 4m、物资区 3m、警戒桩 2m）；
   - 所有物件避开主通道（净距 ≥1m）与场地边界；
   - 放不下时记录为「未放置」并在顶部提示，不会静默丢弃。
4. **手动调整**
   - 左键拖动物件改位置；压到通道/越界/碰撞时自动**弹回最近的合法空位**，拖拽中有红/原色提示；
   - 选中后在右侧检查器单独**旋转（0–359°、可 90° 步进）和改尺寸**，非法变换会被拒绝；
   - 手动改过的物件旁出现橙色「改」记号，并进入右侧「手动调整清单」；
   - 改参数重新生成时，手动物件**留在原处并作为障碍**，不被冲掉；
     若通道改向导致其落入新通道，会被就近挪到合法空位。
5. **种子复现**：同一种子的首次生成会存为快照；点「复现该种子布局」即回到那一版完整
   自动布局（参数一并恢复、清除全部手动调整），与之后改过什么参数无关。
6. **右侧清单**：点条目高亮并聚焦对应物件，可一键「恢复自动位置」（位置回自动点，
   旋转/尺寸等其它手动修改保留；全部还原后物件离开清单）。
7. **导出布置图**：顶栏「导出布置图」生成 1680px 宽 PNG 俯视平面图，含标题与参数摘要、
   指北针、场地长宽、通道宽度、各类同类物件间距（规则值 + 实测值）、图例、比例尺。

## 核心规则与口径

- 全部几何在 2D 平面（x-z）以**有向包围盒 OBB + SAT** 判定；间距统一采用
  **沿两物件中心连线方向的边缘净距**（`centerLineGap`），布置图标注与引擎校验同一函数，
  保证「实测值 ≥ 规则值」。
- 种子经 FNV-1a 哈希后喂给 mulberry32 PRNG，候选网格点随机洗牌，保证同种子可逐位复现。

## 目录结构

```
src/
  lib/
    types.js         物件类型、五档数量、间距等常量
    rng.js           种子哈希与可复现随机数
    layout.js        布置引擎：OBB 判定、种子化生成、最近空位搜索
    store.js         全局响应式状态：生成/复现/手动调整/校验/快照
    SceneManager.js  three.js 场景：建模、射线拾取、拖拽与弹回动画、高亮
    blueprint.js     Canvas 2D 布置图导出
  components/        左侧参数面板、检查器、右侧调整清单
tests/
  engine.test.mjs    引擎单测
  smoke.mjs          无头 Chrome 端到端（?e2e=1 测试钩子，仅测试构建使用）
```
