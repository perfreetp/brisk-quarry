# 珊瑚礁白化演变时间轴展示

面向保护区管理方汇报会的**同一礁区多期模型按时间顺序对比**应用。
技术栈：**Svelte 5（runes）+ Konva 9 + Vite**。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建 → dist/
npm test           # 纯逻辑单元测试（node:test，14 项）
node test/e2e/smoke.mjs   # 端到端冒烟（需先 npm run dev，24 项检查）
```

## 工作流与功能对照

| 汇报工作流 | 应用实现 |
| --- | --- |
| 按监测日期导入各期正射图与白化色块 | 右侧「导入」页：正射图 + 白化 GeoJSON（多边形带 `bleaching` 0–1 属性），自动按日期排序、补建轨道组 |
| 每期生成一条轨道，轨道上两个关键帧 | 底部时间轴每期一条轨道，◆ 显示范围关键帧 + ◆ 色标档位关键帧 |
| 调显示范围框住礁体区域 | 画面拖拽平移、滚轮缩放，或右侧数值/方向键/放大缩小/全礁 |
| 调色标把白化等级分档 | 4 条阈值滑杆，5 个白化等级（正常→死亡），图例实时渐变 |
| 每期调完落一个关键帧 | 「落本期关键帧」按钮，轨道菱形由空心变实心并记录落帧时间 |
| 相邻期轨道编组、组上设过渡时长 | 「轨道组」页逐组滑杆（0.3–4s），过渡带在时间轴上以曲线+时长胶囊显示，<900ms 标「偏快」 |
| 预览从一期渐变到下一期，色块和范围一起过渡 | `stateAt()` 同一查询函数驱动：显示范围插值 + 图层交叉淡入（色块随各自色标渐变） |
| 播放按时间轴从头走，每期停 2 秒 | `HOLD_MS=2000`，requestAnimationFrame 播放，模式芯片显示停留/过渡 |
| 画面下方期次名和监测日期跟着滚 | 字幕条随播放高亮当前/下一过渡期；画面左上角角标同步显示期次+日期 |
| 第三→四期过渡太快 → 拉长，后续整体后挪、刻度重排 | 「一键把第三→四期过渡拉长到 2.0s」或滑杆调整；时间轴为派生数据，后续关键帧自动平移、秒刻度重排（单测+e2e 验证后挪 1300ms） |
| 改某期色标后，之后关键帧按新色标重新对齐 | 勾选「后传对齐」（默认开），阈值整体后传；也可关闭只改本期 |
| 预览和回放结果一致 | 预览拖动与正式播放共用 `stateAt()`，无第二套渲染路径 |
| 播放到某期圈出白化扩大区、暂停放大讲解 | 「圈出扩大区」逐点圈选（双击/Enter 完成，Esc 取消），自动暂停并 450ms 补间放大到该帧，可退出 |
| 整段连续播一遍确认衔接 | 「连续播一遍」回 0 走到尾；空格键播放/暂停 |
| 交给项目负责人放进汇报材料 | 「汇报全屏」进入全屏；「导出工程存档」下载工程 JSON |

## 架构

```
src/lib/
  timeline.js   纯函数：buildTimeline（停留2s+组过渡）、stateAt（插值查询，预览/回放同源）、刻度
  project.js    纯函数 reducer：关键帧、色标后传、组时长、标注、导入、GeoJSON 解析
  color.js      白化分档与颜色插值
  demo-data.js  5 期合成演示数据（正射底图 canvas→dataURL + 35 个演变斑块）
  stores.svelte.js  runes 状态薄封装 + RAF 播放循环
src/components/
  StageCanvas.svelte    Konva 舞台：多期图层交叉淡化、视窗变换、圈选、放大镜头、角标、字幕
  TimelineTracks.svelte SVG 时间轴：轨道/关键帧/组过渡带/刻度/可拖播放头
  KeyframePanel.svelte  关键帧（范围+色标+落帧+标注）、轨道组、导入三个页签
  PlaybackBar.svelte    播放控制与进度条
```

**关键设计**：时间轴不是独立数据，而是 `buildTimeline(project)` 的派生结果——改组时长后无需手动挪关键帧，下一次派生即整体后挪、刻度重排；所有编辑经纯 reducer 返回新对象，单测可直接覆盖。

## 真实数据接入

演示数据结构即真实接入契约：

```jsonc
// 期次
{ "id": "p6", "name": "第六期", "date": "2026-06-01",
  "ortho": "<正射图 dataURL/URL>",
  "patches": [{ "id": "...", "points": [[x,y],...], "bleaching": 0.72 }] }
// GeoJSON：Polygon Feature，properties.bleaching 为 0–1 白化值
```
