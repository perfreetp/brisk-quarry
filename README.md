# 测温电缆与风口布点排版工具

面向粮库保管员的平房仓布点图排版工具。保管员拿着**已埋测温电缆的分层测点编号表**和**通风口清单**,把电缆符号、风口符号按仓房平面尺寸摆到对应位置,生成可指导现场埋电缆、开风口的平面/剖面布点图。

纯原生 TypeScript + Web Components 实现,符号与标注用 [Two.js](https://two.js.org/) 绘制,无前端框架。

## 启动

```bash
npm install
npm run dev        # 开发,默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
```

冒烟测试(需先启动 dev server):

```bash
npm run dev                      # 终端 A
SMOKE_BASE=http://localhost:5173/ npm run smoke   # 终端 B
```

## 五个工作页

| 页面 | 职责 |
| --- | --- |
| **数据录入** | 维护仓房/廒间尺寸、电缆分层测点表、风口清单;支持从 Excel 整块复制后**粘贴 TSV 批量导入** |
| **平面布点** | 按仓房平面摆放电缆/风口符号,每个符号带编号与引线标注,可拖动、自动避让 |
| **剖面布点** | 同一批电缆按埋设深度竖向排进粮堆剖面,风口按风道标高达落;与平面共用编号 |
| **编号规则** | 定义电缆前缀、分层后缀、风口前缀、补零位数;点"重排"整体重新编号 |
| **局部放大** | 只排一个廒间的符号,排好回总图,标注关系不丢 |

## 核心交互

- **拖符号**:左键拖动电缆/风口改位置;最上层有透明热区,即使标注框盖住符号也能直接拖。
- **拖标注**:拖动引线末端的标注框,自动固定(`pinned`),其余标注在它周围重新找空位。
- **右键标注**:切换"固定 / 参与自动避让"。
- **标注整体让一遍**:力导向松弛(框间排斥 + 锚点弱拉力 + 边界软墙),手动固定的标注不动。
- **画布**:滚轮以光标为锚缩放,中键/右键或拖空白平移。
- **双击空白**:按当前工具栏工具(电缆/风口)在该廒间新增符号。
- **撤销/重做**:`Ctrl+Z` / `Ctrl+Y`,拖动合并为一次历史记录。

## 编号规则

规则只决定"怎么编号",实体靠稳定 `id` 与标注绑定,因此重编号后:

- 符号位置、引线、平面/剖面对应关系全部保留;
- 平面改编号,剖面自动跟随(同一份 `Project` 数据);
- 例:前缀 `C`、起始 1、不补零、分层后缀从 1 起 → 电缆 `C1`,其 8 个测点 `C1-1 … C1-8`。

电缆按廒间分组、组内按"从里到外、从左到右"排序;风口在全仓范围连续编号。

## 数据持久化

- 编辑自动存入浏览器 `localStorage`,刷新不丢。
- **导出工程**为 `.layout.json`,可拷贝给他人或归档;**打开工程**读回后符号与标注的对应关系原样恢复,继续改编号和位置。
- JSON 即单个 `Project` 对象,含仓房尺寸、廒间、电缆(含分层测点)、风口、编号规则、双视图(平面/剖面)标注位置与固定状态。

## 关键设计

- **双视图标注独立存储**:每个实体有 `label`(平面)和 `sectionLabel`(剖面)两套标注位置,各自避让、各自固定,但共享实体 id 与编号。
- **热区优先命中**:Two.js 场景最上层绘制透明圆,符号命中优先于标注框,解决"标注盖住符号拖不动"。
- **派生性修改不压栈**:标注避让是位置的派生结果,经 `notifySilently()` 只持久化不进撤销栈,保证一次"重排"可一次撤销。
