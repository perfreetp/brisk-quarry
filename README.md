# 草格林带图册排版工作室

一套面向防护对象布置图的参数化图册工具：从铁路红线/控制中线出发，沿线生成草方格带、灌木林带、桩号、材料表、苗木表、图例和图框，并按 A3 横向图册分页排版。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的地址（默认 `http://127.0.0.1:5173`；若端口占用会自动顺延）。

生产构建：

```bash
npm run build
npm run preview
```

## 已实现的验收链路

1. **原生 TypeScript + Web Components**
   - `<atlas-app>`：工作台、状态、面板和文件操作。
   - `<paper-sheet>`：Paper.js A3 纸面与拖拽交互。
   - `<number-field>`：带滑块和数字框的参数组件。
2. **Paper.js 矢量绘制与排版**
   - A3 横向纸面、图框、标题栏、平面页、材料表续页均为矢量对象。
   - 网格、林带、苗木、桩号、图例、指北针和比例尺全部重绘，不使用截图位图。
3. **opentype.js 工程字体**
   - 内置并加载 `public/fonts/FZFangSong.ttf`（仿宋工程字）。
   - 所有图面文字通过 `font.getPath(...).toPathData()` 转成 Paper 矢量路径；字体加载失败时才回退系统仿宋。
4. **参数联动**
   - 修改草方格纵/横边长、格埂宽度、每延米草料指标：图上网格、方格数、格埂延长米、草料 kg/t、右侧材料表和纸面材料表同步重算。
   - 修改行距、株距、林缘留白、损耗率：行数、有效株数、含损耗需苗量、分树种苗木表同步变化。
5. **红线与桩号**
   - 默认段落为 `K4+000～K6+600`，在 `K4+960` 设置 R25m 急弯，`K5+000` 位于弯道后。
   - 自动生成公里桩、百米桩；曲线范围内按 20m 里程加密。
6. **K5 自交与孔洞**
   - 内侧草方格远边偏距大于弯道半径，故意形成自交偏移边界。
   - 使用 Paper `resolveCrossings()`、`unite()` 和 `subtract()` 做拆分、合并和孔洞扣除；数量按修复后的外环减孔洞净面积计算。
   - 默认在右侧草方格带 `K4+420` 设置一个椭圆预留孔，用于验证孔洞布尔。
   - 布尔异常时回退到原始环和鞋带公式面积，保证排版不白屏。
7. **图面整饰拖拽**
   - 每页指北针、比例尺均可拖拽。
   - 图例块可拖到纸面任意位置；若压住实际布线、侧栏表或标题栏，松手后用网格搜索就近移动到不压图位置。
8. **图例续页**
   - 第 3 页固定包含紫色“图例（续）”块。
   - 顶部“到第 3 页补图例”会跳到第 3 页并追加一条图例。
9. **表格与续页**
   - 每 100m 生成一行分段材料/苗木数量。
   - 表行作为最小排版单元整体分页：首页放 15 行，后续续页每页 24 行，末页追加合计行，不会出现半行跨页断裂。
10. **保存/打开/结构保留**
    - “保存图册”下载 `.atlas.json`，其中包含 `document` 和计算快照。
    - 编辑过程自动写入 `localStorage`。
    - “打开图册”可恢复 JSON；规范化逻辑会补齐缺失图层、字体无关结构和第 3 页续图例入口。
    - 保存结构包含图层、桩号快照、页面、家具位置、规格、树种、孔洞、布尔问题和材料量。
11. **整册输出**
    - “本页 SVG”导出当前矢量页。
    - “图册 HTML/打印”逐页生成内嵌 SVG 的 A3 横向 HTML，可打开后用浏览器打印为 PDF。

## 主要目录

```text
src/
  components/        Web Components（应用、Paper 纸面、数字字段）
  geometry/          里程、偏距、桩号、自交检测、Paper 布尔、工程量计算
  model/             默认 K5 示例工程
  render/            Paper 纸面、表格、图例/指北针/比例尺、opentype 文字
  state/             Store、本地草稿、JSON 保存/打开和规范化
  types.ts           持久化文档与计算结果类型
public/fonts/        内置仿宋工程字体
scripts/             可选的 Puppeteer/Chrome 冒烟验证脚本
```

## 浏览器冒烟验证

Windows 环境且本机装有 Chrome 时：

```bash
npm run dev -- --port 5174
VERIFY_URL=http://127.0.0.1:5174/ node scripts/verify-browser.mjs
```

脚本会验证自定义元素注册、K5 自交问题、面积/株数联动、第 3 页图例追加、图例拖拽持久化和保存 JSON 结构。
