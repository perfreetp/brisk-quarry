# 塘图 · 场区出图工作台

用 **SolidJS + Fabric.js** 搭建的水产场区图则工作台：先铺航拍正射/塘埂测距底图，完成塘口与网箱分区，再叠加增氧点位、覆盖半径、电源管路和投喂路线，最后把三张图排到 A1 横版或 A3 竖版张贴版面。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://127.0.0.1:5173）。

构建生产包：

```bash
npm run build
npm run preview
```

运行版面避让与稿子结构测试：

```bash
npm test
```

## 现场流程

1. **场区 / 分区**
   - 已内置本周航拍正射风格底图、手持测距得到的塘埂闭合/分段尺寸，以及 `6m × 6m` 网箱框架示例。
   - 可上传真实航拍正射图片替换示意底图。
   - 点击“拖画塘口”后在画布上拖出塘口；右侧可改塘口号、品种、规格、面积、放养密度和台账来源。
   - 选中塘口后可一键生成 `4 × 3` 网箱框架。
2. **增氧点位**
   - 从厂商目录把水车式增氧机卡片直接拖进塘里，也可点“放入”。
   - 机器标注编号、功率和安装水深，覆盖圆显示厂商覆盖半径。
   - 可加电源点，并用“拉管路到电源”先点机器、再点电源；正交管路、长度和 DN 管径会保留。拖动机器或电源点，管路自动重算。
   - “导出增氧 PNG”可单独给施工队图片。
3. **投喂路线**
   - 点“沿堤埂画路线”，沿塘埂逐点单击，双击或 Enter 完成。
   - 点“顺序点投喂点”后逐点放置；右侧可改单次投喂时长、饲料类型和顺序。
4. **排版出图**
   - 三张 Fabric 地图分别进入版面卡片。
   - 支持 **A1 横版（841 × 594mm）** 和 **A3 竖版（297 × 420mm）**。
   - 自动生成图例、米制比例尺、指北针和塘口编号表。
   - 可直接在编号表中改塘口号；分区 Fabric 标注、图例中的品种编号索引和表格同步更新。
   - 拖动“⠿ 塘口编号表”或切换幅面时，版面求解器会重新计算三张图、图例和说明卡的位置，保证不压盖。
   - 图例由当前图层和对象派生；在排版页“图层增减”中关闭任意图层，对应图例项立即删除。
   - “打印 / 另存 PDF”使用动态 `@page` 尺寸输出所选 A1/A3 版面。

## 可再编辑稿子

“保存可编辑稿”会下载：

```text
<场名>-可再编辑图稿-<日期>.aquafarm.json
```

稿子包含塘口多边形、网箱框架、品种规格、台账面积密度、增氧机参数、电源点、管路折点、投喂路线和投喂点、版面设置。下周点“打开稿子”选择该 JSON，即可回到排版页，并可分别切回三个图层继续编辑。

应用也会把当前项目自动保存到浏览器 `localStorage`；若上传的航拍图过大导致本机存储配额不足，请以 `.aquafarm.json` 文件稿为准。

## 目录说明

```text
src/
  App.jsx                 # 顶部步骤、文件稿导入、自动保存
  store.js                # Solid 响应式项目模型、示例台账、所有编辑动作
  mapScene.js             # Fabric 场景绘制、标注、机型/电源/投喂点图形、PNG 导出
  legend.js               # 图例派生与塘口自然排序
  layout.js               # A1/A3 毫米版面求解与防压盖算法
  styles.css              # 工作台、海报毫米样式和打印样式
  components/
    MapStage.jsx          # 可交互/只读 Fabric 画布及鼠标、拖放、键盘操作
    Panels.jsx            # 分区、增氧、投喂右侧编辑面板
    LayoutBoard.jsx       # 海报版面、编号表拖动、图例和打印幅面
tests/layout.test.js      # 多位置/幅面防压盖与 JSON 往返测试
scripts/                  # 可选的本机 Chrome 冒烟检查脚本
```

## 已验证

- `npm test`：A1/A3、编号表在多个拖动位置下，地图、图例、编号表两两不重叠；JSON 稿保留三层结构。
- `npm run build`：Vite + Solid 生产构建通过。
- 使用本机 Chrome 冒烟验证：三个工作页渲染、增氧机放入、投喂点新增、编号修改、编号表拖动避让、A1/A3 切换，以及 `.aquafarm.json` 下载后重新打开。
