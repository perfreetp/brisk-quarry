# 隧洞轴线三维放样与岩层穿插校核系统

面向隧洞开挖前的轴线放样、断面模板放样、岩层穿插校核、分段方量与成果导出。界面使用 **Vue 3**，三维编辑、拾取和求交使用 **Three.js + three-mesh-bvh**，所有数据处理均在浏览器本地完成。

## 启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 已实现的工作流

1. **导入纵剖面轴线**：支持 CSV/TXT/JSON，字段可识别 `桩号/K号`、`east/x/东坐标`、`north/y/北坐标`、`elev/z/高程`。桩号支持 `K1+200.00` 格式。
2. **导入地学数据**：
   - 地形 DEM：规则 XYZ/CSV、Esri ASCII Grid（`.asc`）、JSON 栅格；散点自动 IDW 栅格化。
   - 岩层分界面：支持“桩号,高程”的地质纵剖面曲线（沿当前轴线横向展布），也支持 XYZ 三维界面。
   - 未准备文件时可直接使用内置示例 DEM、岩层界面和轴线。
3. **轴线与桩号**：三维显示控制折线、平滑轴线、每 10 m 小刻度和每 20 m 桩号标签。
4. **控制点编辑**：
   - 直接拖动青色控制点；默认平面移动，可切换“高程拖动”或按住 `Shift` 拖动。
   - 侧栏实时显示平曲线近似半径、进口坡和出口坡。
   - 可插入、删除或精确编辑控制点。
5. **断面模板**：
   - 马蹄形、圆形一键切换。
   - 模板库包含不同净宽/直径，可编辑宽、高、边墙高、仰拱深度、超挖余量和周边离散数。
   - 净面积由闭合断面多边形计算，开挖面积计入超挖余量。
6. **按桩号分段放样**：
   - 按标准桩号间隔生成独立分段 Mesh。
   - 点击三维洞身或表格行可选中分段，查看桩号、长度、坡度、净面积、开挖面积和方量。
7. **岩层穿插 BVH 校核**：
   - 岩层界面和洞身几何均建立 `MeshBVH`。
   - 拾取使用 `acceleratedRaycast`。
   - 拖动期间以低边数、单跨 LOD 实时重建并执行 `intersectsGeometry`；相交分段立即染红，右侧栏和表格同步列出桩号。
8. **高程衔接**：
   - 可输入目标坡度并自动顺接相邻共享边界。
   - 可手工编辑起终点高程；错台超过容差时，在“高程衔接”和表格中标出对不齐的分段、桩号和错台值。
   - 支持一键顺接。
9. **按段加密**：每段可 ×2、×4 加密放样环数；拖动时仍使用轻量 LOD，松手后恢复全精度，保证加密后拖动跟手。
10. **撤销/重做**：`Ctrl/⌘+Z`、`Ctrl+Y` 或 `Ctrl+Shift+Z`。快照包含轴线、模板、桩号间隔、加密倍数和高程调整；回退后洞身、红色穿插标记、问题列表和方量表一起恢复。
11. **成果导出**：
    - **CSV 方量表**：逐段桩号、面积、方量、加密和穿插状态，带 UTF-8 BOM，Excel 直接打开不乱码。
    - **IFC4**：每个桩号分段为一个 `IfcBuildingElementProxy` 三角面实体，写入起点/终点桩号、长度、开挖面积、方量、加密倍数和岩层穿插属性。

## 主要目录

```text
src/
  components/
    Viewport3D.vue   # Three.js 场景、BVH 拾取、拖动、放样、求交
    LeftPanel.vue    # 导入、轴线编辑、模板、图层
    RightPanel.vue   # 穿插列表、高程衔接、分段属性、历史
    BottomTable.vue  # 桩号方量表
    TopBar.vue
  lib/
    alignment.js     # 桩号映射、曲线、局部框架、半径/坡度
    sections.js      # 马蹄形/圆形断面与面积
    loft.js          # 沿轴线放样和 BVH Geometry
    model.js         # 分段记录、方量、衔接问题
    parsers.js       # 轴线、DEM/ASC、地质剖面解析
    csv.js           # 方量表 CSV
    ifc.js           # IFC4 分段导出
  actions/io.js      # 文件读取和导出动作
  store.js           # 响应式状态与历史快照
```

## 说明

- 大测量坐标会以首个导入点或 DEM 原点建立局部工程坐标，避免 Three.js 大坐标精度问题；IFC 当前导出该局部工程坐标。
- 拖动时的实时求交使用粗放样 LOD，松手后会按完整模板精度和加密倍数重建最终结果。
