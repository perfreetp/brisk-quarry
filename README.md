# 逐洞击球路线标注工具

Svelte + Konva 实现,供球场设计师与赛事总监协作的逐洞击球路线标注与码数本排版工具。

## 运行

```bash
npm install
npm run dev    # http://127.0.0.1:5173
npm run build  # 产出 dist/
```

## 工作流程

### 设计师
1. **新建洞** → 导入平面图(位图)→ 用「定比例尺」在图上点两个已知距离的点,输入实际码数,确定该洞比例尺(每洞独立,互不影响)。
2. **画球道中心线**、**果岭轮廓**(单击加点,右键撤点,回车/双击完成,Esc 取消)。
3. **画参照线**:沙坑唇口 / 水障碍岸线 / 草皮边,绘制进攻线时可吸附。
4. **进攻折线**:沿障碍距离刻度(中心线上按间隔生成的码数刻度)拉线,每个拐点自动吸附到最近刻度或参照线;点旁自动标注:距发球台码数、距果岭前沿剩余码数、最近障碍距离、进攻角度。
5. **落球区**:矩形圈定,可选中后改目标差点与风向,支持拖动/缩放/旋转。

### 标注排版规则
- 码数分档:<100y 显示完整码数(一位小数)且字号最大;100–200y、>200y 只留整数,字号递减。
- 密集处标注自动垂直错开并带引线,不压折线。
- 手调过的标注偏移保存在 `labelManual`,任何重算/重排后保留。

### 赛事总监
切到「赛事总监」后只保留选择/拖动与落球区工具:拖落球区、拖进攻线拐点(仍吸附刻度)、拖标注。码数随拖动自动重算,标注自动重排,手调偏移保留。整版可叠十几个洞,每洞独立坐标系(码),改某洞刻度间隔/比例尺不影响其他洞。

### 码数本
「码数本」视图按洞分页(A4),每页含:进攻线缩略图、落球区(目标差点/风向)、逐点障碍距离与进攻角度表。可直接浏览器打印成 PDF。

### 矢量导出 / 导入
- **导出矢量图**:整版 SVG,`<metadata>` 内嵌完整结构 JSON。
- **导出码数本 SVG**:每洞一页独立 A4 矢量文件。
- **导入矢量/JSON**:从 SVG metadata 或 JSON 还原全部结构,折线、落球区、标注仍可单独选中编辑,手调偏移不丢。

数据自动保存在浏览器 localStorage。
