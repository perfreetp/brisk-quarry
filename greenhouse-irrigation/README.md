# 温室灌溉管网分段接出工具（React + Paper.js）

面向种植园区设施农业技术员的灌溉管网设计工具：从水源首部出发布置主管，自动接出
贴苗床走向的支管，按流量/间距排布滴头与喷头，并沿程做水力分段与合规检查。

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
```

## 功能与实现对应

| # | 需求 | 实现位置 / 操作方式 |
|---|------|--------------------|
| 1 | 首部起画主管、沿棚体纵向到棚尾、按设备参数选管径 | `lib/network.js` 主管分段；左侧「主管管径」DN16–DN200 目录（`lib/pipes.js`） |
| 2 | 按支管间距自动分出支管、贴苗床走向 | 支管中心线 = `间距×(i+0.5)`，与画布苗床同公式；画布绿色竖线即支管 |
| 3 | 按滴头流量/间距排滴头，喷头区段换喷头并按射程排布 | `buildLaterals()`：滴头等间距排布；喷头间距 = `0.8×2R`，虚线圆表示射程 |
| 4 | 按流量压力分段、超压降段标黄并提示加粗/缩短 | 海曾-威廉公式（`pipes.js#headLossMPa`）；超段画黄色，清单与检查器给出加粗一档 DN 和最大允许长度 |
| 5 | 改上游主管管径，下游自动重算，手动调整保留 | 全部计算在 `buildNetwork(params, overrides)` 纯函数内；手动值存 `overrides`，重算不覆盖 |
| 6 | 拖滴头改间距只影响本支管 | 拖支管上第一个放大滴头 → `SET_LATERAL_SPACING` 仅写该支管覆盖项，相邻支管不动（有测试断言） |
| 7 | 种子决定整套排布，同参数重生成完全一致 | `lib/rng.js`（xfnv1a 哈希 + mulberry32）；同种子两次生成 JSON 深比较相等（有测试断言） |
| 8 | 首部标压力分段、每段末端挂压力标注 | `pressureNodes` 从水源压力逐段扣损；画布每个三通处画刻度与 kPa 标注，三层轮换防重叠 |
| 9 | 检查支管穿作业道，红框圈出并列清单 | 支管偏离本床中心线超床宽一半即判穿道；画布红色虚线框 +「穿道」角标，右侧清单可点击定位 |

## 画布交互

- **拖三通圆点**：整条支管沿主管移动（手动位置，重算保留）
- **拖首个滴头（放大的绿点）**：上下拖改本支管滴头间距，相邻支管不受影响
- **点主管段**：右侧检查器查看分段流量/压降/流速，可单独手动改本段管径
- **点支管/滴头/喷头**：打开支管检查器，可一键恢复自动位置或默认间距
- 「自动按压降分段选管径」开启后，系统逐段自动选满足允许压降的最小 DN

## 水力模型说明

- 沿程损失：海曾-威廉公式，PE/PVC 取 C=150
- 支管为多点出流毛管，等效损失按直通管 ×0.6 折减（规范常用系数）
- 流量从棚尾向首部逐段累加，压力从首部向棚尾逐段扣减
- 模型用于方案比选与告警提示，不替代正式水力计算书

## 目录结构

```
src/
  lib/rng.js            种子随机数（确定性）
  lib/pipes.js          管材目录、海曾-威廉损失/流速
  lib/network.js        几何生成 + 水力分段 + 合规检查（纯函数）
  state/useNetwork.js   reducer：参数与手动覆盖分离
  components/PaperCanvas.jsx   Paper.js 画布：渲染、命中、拖拽
  components/ControlPanel.jsx  左侧参数面板
  components/IssueList.jsx     右侧检查清单（穿道/水力告警）
  components/SelectionInspector.jsx  选中对象属性与手动调整
```
